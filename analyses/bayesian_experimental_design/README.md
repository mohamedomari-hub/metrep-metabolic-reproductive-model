# Bayesian Experimental Design

This folder contains the MATLAB reference BED workflow and Python
GitHub-facing BED reproductions.

The final BED workflow uses a broad `+/-5%` prior archive for posterior
distributions and ODE-confirmed admissible ensembles for ranking stability,
global sensitivity links, uncertainty-window targeting, and MI summaries.

Generated BED banks, debug outputs, and run outputs are intentionally ignored
by Git. Curated BED figures and traceability tables are copied to
`results_final/`.
