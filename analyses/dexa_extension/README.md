# Dexamethasone Extension

The original MATLAB reference model includes dexamethasone PK/PD states and
dose handling. The current Python implementation does not yet implement the
Dexa module.

This module documents the planned Python extension and should not be presented
as completed until Python trajectories are validated against the MATLAB
reference.

The scientific role of Dexa is perturbation validation: it checks whether the
model can reproduce expected metabolic responses under dexamethasone
administration, beyond baseline reproductive-metabolic dynamics.
