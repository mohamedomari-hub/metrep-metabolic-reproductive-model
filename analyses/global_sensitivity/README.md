# Global Sensitivity

This folder contains the global sensitivity and admissible-bank association
screening workflows.

The final portfolio analysis uses ODE-confirmed admissible simulations and
summarizes parameter-biomarker AUC associations with Spearman correlation and
PRCC. These metrics are complementary association screens, not strict Sobol
variance decompositions.

Generated output folders such as `outputs/`, `outputs_enriched/`, and
`outputs_smc_enriched_5pct_glucagon/` are intentionally ignored by Git. Curated
figures and tables are copied to `results_final/`.
