# Combined Parameter Summary

Local sensitivity measures nominal one-at-a-time AUC response. PRCC/Spearman summarize parameter-biomarker AUC associations across biologically admissible simulations. Identifiability class comes from representative profile likelihood behavior. These metrics are complementary and should not be interpreted as identical sensitivity measures.

Interpretation tags use a high-global-association threshold of 0.30, a low-global-association threshold of 0.10, and the upper quartile of all-parameter local sensitivity as the high-local threshold.
