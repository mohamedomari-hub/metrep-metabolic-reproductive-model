# Uncertainty Propagation

This folder contains uncertainty-propagation plotting and summary scripts.

The final figures summarize ODE-confirmed admissible trajectory ensembles using
the median trajectory, 5th-95th percentile band, and nominal trajectory overlay.
The enriched admissible bank is used for ensemble coverage; surrogate-predicted
candidates are not used as scientific truth.

Generated local output folders are ignored by Git. Curated figures and tables
belong in `results_final/`.
